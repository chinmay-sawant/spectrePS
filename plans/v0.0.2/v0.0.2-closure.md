## Overview

`go test -p n` is how many test binaries run at once. The default is `GOMAXPROCS`. `-parallel` is different: it only limits `t.Parallel` tests inside one package. Source: [cmd/go, -p](https://pkg.go.dev/cmd/go).

Local `make test` is the gate. This file does not add CI.

## Executive summary

`make test` now passes `-p` with the machine's CPU count, from `nproc`, so package tests run together instead of leaving the parallelism implicit. `make lint` is unchanged. Phases 1 to 3 are not closed by this file.
